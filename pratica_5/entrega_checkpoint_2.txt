RESUMO DA ENTREGA
No Checkpoint 1, foi implementado e validado na Raspberry Pi um serviço
systemd para inicialização automática de um programa Python de controle
de LED, incluindo testes de funcionamento após a reinicialização do sistema.

O Checkpoint 2 apresenta a documentação integrada do projeto e a
continuidade do uso de Git e GitHub pelo grupo desde as primeiras
atividades da SEL0337. O README específico registra os procedimentos
realizados, os conceitos envolvidos e as evidências obtidas no laboratório.

O arquivo historico_git.txt, disponível no item 4, apresenta o histórico
real de commits do repositório, documentando a evolução das atividades
desde a Prática 1 até a entrega final da Prática 5.
