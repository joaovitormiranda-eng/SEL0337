# Prática 5 — Serviços de Inicialização e Git/GitHub

**SEL0337 — Projetos em Sistemas Embarcados**

Esta prática integra uma aplicação embarcada gerenciada pelo **`systemd`** e a documentação de seu desenvolvimento em **Git/GitHub**. A Raspberry Pi foi utilizada para demonstrar o acionamento automático de um LED após o boot; o projeto e suas evidências foram organizados no repositório da disciplina.
